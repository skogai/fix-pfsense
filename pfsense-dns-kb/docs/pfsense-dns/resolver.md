# DNS Resolver¶

The DNS Resolver in pfSense® software utilizes `unbound`, which is a validating, recursive, caching DNS resolver capable of using DNSSEC, DNS over TLS, and a wide variety of options. It can act in either a DNS resolver or forwarder role.

Note

The DNS Resolver is enabled in resolver mode by default in current versions of pfSense software.
