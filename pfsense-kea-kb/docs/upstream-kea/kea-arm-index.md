# Kea Administrator Reference Manual

Kea is an open source implementation of the Dynamic Host Configuration Protocol (DHCP) servers, developed and maintained by Internet Systems Consortium (ISC).

This is the reference guide for Kea version 3.3.1-git. Links to the most up-to-date version of this document (in PDF, HTML, and plain text formats) can be found on [Read the Docs](https://kea.readthedocs.io). Other useful Kea information can be found in our [Knowledgebase](https://kb.isc.org).
